# Ayush Thakur — Full-Stack Developer · Vol. 01

A portfolio web application built with **React**, **TypeScript**, **Vite**, and **GSAP**, preserving the signature manga ink and screentone aesthetic.

## Features

- **Manga Ink Aesthetic**: Custom manga comic panels, screentones, halftones, speed lines, and character ink art.
- **Dynamic Routing & State**: Instant transitions between the main volume cover and in-depth project case study dossiers.
- **Chapter Navigation**:
  - **Cover & Marquee**: Vol. 01 header, live stats, squad art (Attack on Titan, Naruto, Dragon Ball inspiration), and animated ticker.
  - **Chapter 01 (Origin)**: Developer background, Nindō quote, and core technical metrics.
  - **Chapter 02 (Missions)**: Filterable portfolio of live shipped applications (The Pasha Atelier, Brainchild Games / NexStudio, Archive N°9, EditingBox) with live links, tech stacks, and detailed case files.
  - **Chapter 03 (Arsenal)**: Technical stack with transparent trade-offs, custom SVG iconography, and Japanese kanji seals.
  - **Chapter 04 (Process)**: "From Sketch to Ship" 4-panel comic flow with concrete deliverables.
  - **Chapter 05 (Intel & Rates)**: Transparent sprint pricing tiers, sub-1.5s performance guarantees, honest trade-offs, and client FAQs.
  - **Finale (Contact)**: Direct Gmail compose integration, WhatsApp messaging, LinkedIn connection, and clipboard copy with instant feedback.
- **Interactive Lightbox**: Fullscreen inspection of desktop and mobile live screenshots.
- **GSAP Motion**: Smooth scroll triggers, card tilts, and magnetic button physics with full `prefers-reduced-motion` support.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Motion**: GSAP + ScrollTrigger
- **Styling**: Handcrafted CSS with manga panel layout, halftone textures, and custom typography

## Development
